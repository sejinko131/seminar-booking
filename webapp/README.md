# 공공인재학부 세미나실 대관 웹앱

선거관리시스템 `cau-pa-referendum-2026`의 Python 표준 라이브러리 서버 + SQLite + HTML/CSS/JavaScript 구성과 화면 스타일을 적용한 별도 세미나실 시스템입니다. 원본 Streamlit 앱은 유지합니다. 선거 데이터·설정·발송키를 복사하지 않습니다.

## 기능

- 일반예약: 오늘~3주 이내, 서로 다른 2~30명, 10분 단위, 이용자 학번별 하루 총 3시간. 자정 경계에서 날짜별 합산.
- 정기대관: 이번 달 안에서 복수 요일 반복, 1회 3시간 이하. 신청은 승인 대기이며 확정 시간표를 차단하지 않음.
- 관리자 승인·반려·취소, 신규 접수 ON/OFF.
- 월·주차 선택 주간 시간표, 확정 예약만 공개, KST 기준 60초 갱신.
- 예약번호 + 이용자가 지정한 8자 이상 비밀번호로 조회·시간 변경·취소. 수정 후 정기대관은 재승인.
- SQLite BEGIN IMMEDIATE로 충돌 확인과 쓰기 원자 처리, 고유 예약 ID·버전 검사, 기록 취소 상태와 감사 내역 유지.
- HttpOnly/SameSite 쿠키, HTTPS origin의 Secure 쿠키, 30분 세션, 요청 출처·Host 검사, 요청 크기 제한, 인증 시도 제한.

학교 구성원 자격 인증은 포함하지 않습니다. 이름·학번 입력과 예약 관리 비밀번호는 재학생 자격을 증명하지 않습니다. 문자 발송과 명부 연동은 별도 설정·운영 결정이 필요합니다. 출입 비밀번호는 포함하거나 표시하지 않습니다. 승인 정책과 관리 비밀번호는 기존 기능을 옮기는 과정에서 보완한 부분입니다.

## 실행

Python 3.10 이상, 외부 패키지 없음:

```sh
python webapp/server.py --port 8769
```

http://127.0.0.1:8769/ . 관리자 아이디는 환경변수 `SEMINAR_ADMIN_ID`(기본 admin), 비밀번호는 `SEMINAR_ADMIN_PASSWORD`를 12자 이상 지정합니다. 설정이 없으면 관리자 로그인은 차단됩니다. 비밀번호를 저장소에 넣지 마세요.

```sh
cd webapp
python -m unittest -v test_server
node --check public/app.js
```

DB 기본 경로는 `webapp/private-data/seminar.sqlite`. 운영은 `--db /var/lib/cau-pa-seminar/seminar.sqlite --origin https://<대관용 도메인>`을 지정하고 HTTPS reverse proxy 뒤에서 실행합니다. 기존 선거 포트 8768과 다른 8769를 사용합니다.

## 배포

`deploy/seminar.service`와 `deploy/seminar.nginx`는 참고 템플릿입니다. 도메인·인증서 경로·작업 경로를 실제 서버에 맞게 설정한 뒤 사용합니다. 기존 선거 서비스·Nginx 설정을 덮어쓰지 마세요. 환경 파일은 서버에만 만들고 접근 권한을 제한합니다. 서비스 계정이 DB 디렉터리에 쓰기 권한을 갖도록 설정합니다. 이 앱은 공개 origin Host를 검사하므로 Nginx는 템플릿처럼 공개 Host를 그대로 전달해야 합니다.

DB의 names/student IDs/contact/attendees는 개인정보입니다. 정기 백업·접근 제한·보관 기간을 운영 정책에 맞게 적용하세요. SQLite 운영은 동일 호스트의 로컬 디스크를 사용하며 여러 호스트에 DB를 복제해 각각 쓰지 마세요.

기존 Google Sheets 데이터는 자동으로 가져오지 않습니다. 운영 데이터 조회·수정·삭제·마이그레이션은 이번 변경에 포함하지 않습니다. 기존 예약을 옮기려면 별도 읽기 전용 내보내기·건수 및 시간 대조를 먼저 진행해야 합니다.

## 검증 범위

자동 검사는 예약·충돌·자정 경계·학번별 사용 한도·정기 승인·변경 재심사·취소·버전 충돌·동시 예약·HTTP 인증·개인정보 비공개를 확인합니다. 브라우저 실제 화면 QA와 실서버 배포는 별도입니다. 문자·외부 인증키·운영 계정 변경은 수행하지 않습니다.
